Use with MCP

Connect an MCP-compatible assistant directly to the public Food-'O'-Copoeia search and product data. The server is read-only and does not require an API key.

Endpoint

https://open-foodocopoeia.thakerinnovations.com/mcp

Claude Code

claude mcp add --transport http foodocopoeia https://open-foodocopoeia.thakerinnovations.com/mcp

Other MCP clients

Add a remote server using the Streamable HTTP transport. Clients that use JSON configuration generally accept the following shape:

{
  "mcpServers": {
    "foodocopoeia": {
      "type": "http",
      "url": "https://open-foodocopoeia.thakerinnovations.com/mcp"
    }
  }
}

Configuration names vary by client; use the endpoint above whenever a client asks for a remote MCP or Streamable HTTP URL.

Available tools

  • search_food_products — fuzzy, weighted product search
  • get_food_product — complete quality, microbiological, residue, contaminant, additive, and fatty-acid data for one product
  • get_dataset_metadata — snapshot, counts, checksums, and disclaimer

How it works

Your assistant chooses a tool and sends a structured request to this endpoint. The server searches the same published snapshot used by this website and returns structured JSON. It cannot modify data or perform private actions.
